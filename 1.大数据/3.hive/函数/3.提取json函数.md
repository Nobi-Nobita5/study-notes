`from_json`函数用于将JSON格式的字符串转换为结构化的数据类型,`from_json`函数通常与`get_json_object`等其他JSON处理函数一起使用，以提取和操作JSON数据中的特定字段。



`json_tuple` 是 MaxCompute 中专门用于从 JSON 字符串中**高效提取多个字段**的内置函数，它与 `get_json_object` 类似但更高效，以下是它的核心特性和用法：

~~~sql
-- 原始JSON结构:
-- {
--   "order_id": "1001",
--   "items": [{"sku":"A01","price":299},{"sku":"B02","price":599}],
--   "address": {"province":"江苏","city":"苏州"}
-- }

-- 提取订单基本信息
SELECT 
  o.order_id,
  a.province,
  a.city,
  size(i.items) as item_count
FROM (
  SELECT 
    json_tuple(raw_json, 'order_id', 'items', 'address') 
    as (order_id, items, address)
  FROM order_table
) o
LATERAL VIEW 
  json_tuple(o.address, 'province', 'city') a as province, city
LATERAL VIEW
  explode(cast(o.items as array<string>)) i as items;
~~~



-------

| 特性             | json_extract_array         | json_extract     | get_json_object |
| :--------------- | :------------------------- | :--------------- | :-------------- |
| **专用用途**     | 仅处理JSON数组             | 通用JSON提取     | 通用JSON提取    |
| **返回值类型**   | 直接返回ARRAY<STRING>      | 返回JSON格式     | 返回STRING      |
| **路径参数**     | 必须指定数组元素路径'$[*]' | 支持任意JSONPath | 支持简化路径    |
| **嵌套数组处理** | 可多层提取                 | 需要组合操作     | 无法直接处理    |
| **使用复杂度**   | 数组操作更简单             | 中等             | 简单但功能弱    |

json_extract_array参数支持多层嵌套数组（如`'$.a.b[*].c[*]'`）

### 实际使用对比

#### 示例JSON数据：

json

```
{
  "data": {
    "items": [
      {"id": 1, "values": [10, 20]},
      {"id": 2, "values": [30, 40]}
    ]
  }
}
```

#### 1. 使用`json_extract_array`（最佳实践）

sql

```
-- 提取items数组（返回ARRAY<STRING>）
SELECT 
  json_extract_array(json_column, '$.data.items[*]') AS items_array
FROM table;

-- 提取嵌套values数组
SELECT 
  json_extract_array(
    json_extract(json_column, '$.data.items[0]'),
    '$.values[*]'
  ) AS values_array
FROM table;
```

#### 2. 使用`json_extract`的替代方案

sql

```
-- 需要额外类型转换
SELECT 
  cast(
    json_extract(json_column, '$.data.items') 
    AS ARRAY<STRING>
  ) AS items_array
FROM table;
```

#### 3. 使用`get_json_object`（不推荐）

sql

```
-- 无法直接获取数组，只能获取字符串形式
SELECT 
  get_json_object(json_column, '$.data.items') AS items_string
FROM table;
```

### 性能最佳实践

1. **多层嵌套数组提取**：

sql

```
-- 直接提取二级嵌套数组
SELECT 
  json_extract_array(
    json_extract_array(json_column, '$.data.items[*]')[1],
    '$.values[*]'
  ) AS second_level_array
FROM table;
```

1. **配合LATERAL VIEW使用**：

sql

```
SELECT 
  t.id,
  exploded_value
FROM (
  SELECT 
    cast(json_extract(json_column, '$.data.items[*].id') AS ARRAY<BIGINT>) AS ids,
    json_extract_array(json_column, '$.data.items[*].values[*]') AS values_array
  FROM table
) t
LATERAL VIEW explode(t.values_array) v AS exploded_value;
```

### 注意事项

1. **类型一致性**：

   - `json_extract_array`始终返回ARRAY<STRING>

   - 需要显式转换到具体类型：

     sql

     ```
     cast(json_extract_array(...) AS ARRAY<INT>)
     ```

2. **空值处理**：

   - 路径不存在时返回NULL而非空数组

   - 建议用`COALESCE`处理：

     sql

     ```
     COALESCE(
       json_extract_array(json_column, '$.non_existent_path[*]'),
       array()
     )
     ```

3. **性能优势**：

   - 比组合使用`json_extract`+`cast`效率高30%+
   - 特别适合处理大型JSON数组

这种设计使`json_extract_array`成为处理JSON数组的最高效选择，尤其在大数据量场景下优势明显。
